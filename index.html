בחירת כל הגלריה

אתר לא יכול לפתוח את כל הגלריה בעצמו, אבל בחלון הבחירה של האייפון אפשר לסמן אלפי תמונות בתנועה אחת:

  1. לחץ על פתח את הגלריה למטה. אם נפתח תפריט, בחר ספריית תמונות (Photo Library).
  2. הנח את האצבע על התמונה האחרונה (למטה מימין), וגרור אותה למעלה ושמאלה בלי להרים, עד הקצה העליון של המסך.
  3. השאר את האצבע בקצה העליון: המסך יגלול לבד ויסמן את כל התמונות בדרך, עד ההתחלה של הגלריה.
  4. לחץ הוסף (Add). עם אלפי תמונות, האייפון יכול להכין אותן כמה דקות.
טיפ: בגלריה גדולה מאוד (יותר מ-2,000 תמונות) עדיף לעבוד בסבבים של כ-1,000. האתר זוכר מה כבר מיינת, ותמונות שכבר עברת עליהן לא יחזרו.

הגדרת קיצור הדרך

עושים את זה פעם אחת בלבד. דפדפן לא יכול למחוק מהגלריה בעצמו, אז האתר מעביר לקיצור הדרך את רשימת התמונות (לפי זמן הצילום המדויק, עד השנייה), וקיצור הדרך מוחק אותן.

  1. פתח את אפליקציית קיצורים (Shortcuts), לחץ + וקרא לקיצור הדרך בדיוק Swipeclean.
  2. הוסף את הפעולה Get Dictionary from Input (קבל מילון מהקלט). למעלה יופיע "Receive Any input from Nowhere". ליד If there's no input בחר Get Clipboard.
  3. הוסף Get Dictionary Value, מפתח from, ואחריו Set Variable בשם From.
  4. שוב Get Dictionary Value על ה-Dictionary מצעד 2, מפתח to, ואחריו Set Variable בשם To.
  5. שוב Get Dictionary Value על ה-Dictionary, מפתח times, ואחריו Set Variable בשם Times.
  6. הוסף Find Photos ← Add Filter ← Date Taken ← is between. בשני השדות בחר את המשתנים From ו-To. בטל את Limit.
  7. הוסף Repeat with Each על Photos.
  8. בתוך הלולאה: Format Date. לחץ על Date ובחר Repeat Item, ואז לחץ עליו שוב ובחר Date Taken. Date Format: Custom, ובשדה הפורמט כתוב: yyyy-MM-dd HH:mm:ss
  9. עדיין בלולאה: If ← בחר את Times ← contains ← Formatted Date.
  10. בתוך ה-If: Add to Variable, בחר Repeat Item, שם המשתנה ToDelete.
  11. אחרי End Repeat (מחוץ ללולאה): Delete Photos ← בחר ToDelete.
בדיקה ראשונה: צלם 2-3 צילומי מסך, סמן אותם למחיקה באתר, ובדוק שרק הם נמחקו. האייפון תמיד ישאל "בטוח?" לפני המחיקה ויראה כמה תמונות יימחקו, אז אם המספר לא נכון אפשר לבטל.
